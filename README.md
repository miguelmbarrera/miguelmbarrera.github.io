# Página de perfil · Miguel Martínez

Página publicada en **https://miguelmbarrera.github.io**

## Cómo cambiar la información

1. Entra a github.com con tu cuenta y abre este repositorio.
2. Haz clic en el archivo **`perfil.js`**.
3. Toca el ícono del **lápiz** (Edit this file), arriba a la derecha.
4. Cambia solo el texto que está **entre comillas**. No borres comillas, comas ni corchetes.
5. Toca **Commit changes…** y luego otra vez **Commit changes**.
6. En 1 o 2 minutos la página se actualiza sola. Si no ves el cambio, recarga la página en el navegador.

### Cambios frecuentes

| Quiero… | Qué cambio en `perfil.js` |
|---|---|
| Ocultar «Abierto a nuevos retos» | `disponible: false` |
| Cambiar la frase de presentación | el texto de `frase` |
| Agregar un logro | copia una línea de `impacto` y cambia su texto |
| Agregar un cargo nuevo | copia un bloque de `experiencia` y ponlo de primero, con `actual: true` |
| Mostrar el botón de hoja de vida | sube el PDF al repositorio y pon su nombre en `hojaDeVida` |
| Cambiar la fecha del pie | `actualizado` |

### Cambiar la foto

Sube una imagen nueva con el nombre **`foto.jpg`** (Add file → Upload files). Reemplaza la anterior.

## Archivos

- `index.html`: diseño de la página. No hace falta tocarlo.
- `perfil.js`: toda tu información. Es el único archivo que editas.
- `foto.jpg`: tu foto.
